# Calibration file format

A calibration file is a UTF-8 CSV with one row per **measured spectrum**. Each physical drawdown
made over a black-and-white chart produces two rows: one read on the white area, one on the
black area. Lines that start with `#` are comments.

JSON Schema for a single row (cell syntax): [`calibration_row.schema.json`](calibration_row.schema.json).
Cross-field rules below are enforced by the validator (`paintmixer validate file.csv --paints paints.csv`,
or `POST /api/v1/calibration/validate`).

## Columns

| Column | Required | Content |
|---|---|---|
| `sample_id` | yes | Unique id. Substrate rows are `SUB-W` and `SUB-B`. Tint and mixture rows end in `-W` (white background) or `-B` (black background), e.g. `TN-quinacridone-magenta-15-W`. |
| `type` | yes | `substrate_white`, `substrate_black`, `masstone_over_white`, `masstone_over_black`, `tint`, `mixture` |
| `substrate` | yes | `white` or `black`. Must agree with masstone/substrate types. |
| `components` | yes | `paint_id:fraction;paint_id:fraction` — **volume** fractions summing to 1 (±0.002). Empty for substrate rows. Masstones have one paint at 1; tints have one paint plus a white. |
| `notes` | yes (may be empty) | Semicolon-separated tokens: `gap_um=150` (applicator gap in µm; default 150), `holdout` (exclude from the fit; use for validation), any other bare words are a free-text comment. Unknown `key=value` tokens produce a warning. |
| `components_mass_g` | no | Actually weighed masses, `paint_id:grams;...`. When present it **overrides** `components`: masses are converted to volume fractions with each paint's density. A warning is issued when any fraction differs from the planned one by more than 2 percentage points. |
| `r400` … `r700` | yes | Reflectance, 0–1 (values up to 1.2 accepted), 31 columns at 10 nm. |
| `sd400` … `sd700` | no | Per-band standard deviation of the repeat readings (written by `paintmixer measure session`). |
| `measured_at`, `n_readings` | no | ISO timestamp, number of readings averaged. |

### Wavelengths

The canonical grid is 400–700 nm at 10 nm. Files may use any evenly spaced `r<nm>` grid that
covers 400–700 nm (e.g. the ColorMunki's 380–730 nm); such spectra are resampled by linear
interpolation and a `resampled` warning is reported. Header errors (`r55O`, missing `r700`,
duplicate, out-of-order or unevenly spaced columns) stop validation.

## Sample types and what they teach the model

| Type | Purpose |
|---|---|
| `substrate_white` / `substrate_black` | Reflectance of the chart areas. Used as the background for every finite-thickness prediction. |
| `masstone_over_white` / `_over_black` | Pure paint at the standard gap. Initial K/S guess; the pair constrains opacity (scattering). White is drawn as a thickness series (75/150/300 µm by default), which fixes the optical-thickness scale `τ(λ)`. |
| `tint` | Paint + white (chromatic 5/15/35/65 %, black 1/3/10/30 %). Main source of each paint's S relative to white. |
| `mixture` | Pairs and multi-paint mixes. Tests additivity; mixtures flagged `holdout` form the validation set. |

## Validation messages

Every issue carries the CSV line number (header = line 1), the column name and a code:

| Code | Severity | Meaning |
|---|---|---|
| `missing_column`, `bad_wavelength_header`, `missing_spectrum` | error | header problems |
| `bad_type`, `bad_substrate`, `substrate_mismatch` | error | row classification |
| `bad_sample_id`, `duplicate_sample_id`, `missing_value` | error | ids |
| `bad_component`, `duplicate_component`, `unknown_paint`, `fractions_sum`, `bad_masstone`, `bad_tint`, `unexpected_components` | error | composition |
| `not_numeric`, `out_of_range` | error | spectrum cells (the message hints when values look like percent) |
| `bad_gap` | error | `gap_um` is not a positive number |
| `mass_deviation` | warning | weighed masses differ from plan by > 2 pp |
| `missing_pair` | warning | a tint/mixture has only one background |
| `resampled`, `unknown_note_key`, `holdout_ignored`, `unknown_column` | warning | informational |

Rows with errors are excluded; the rest of the file is still reported.

## Example

```csv
sample_id,type,substrate,components,notes,components_mass_g,r400,r410,...,r700
SUB-W,substrate_white,white,,,,0.8187,0.8301,...,0.8697
SUB-B,substrate_black,black,,,,0.0262,0.0270,...,0.0339
MT-titanium-white-75-W,masstone_over_white,white,titanium-white:1,gap_um=75,,0.8050,...
TN-quinacridone-magenta-15-W,tint,white,quinacridone-magenta:0.15;titanium-white:0.85,gap_um=150,quinacridone-magenta:1.22;titanium-white:8.78,0.61,...
PR-phthalo-blue-arylide-yellow-50-B,mixture,black,phthalo-blue:0.5;arylide-yellow:0.5,gap_um=150;holdout,phthalo-blue:4.79;arylide-yellow:5.22,0.05,...
```

Complete synthetic examples: `sample_data/calibration_starter5.csv` (5 paints, 124 rows) and
`sample_data/calibration_pool9.csv` (9 paints, 308 rows), generated by `make sample-data`.

## Scope

Geometry 45/0 with UV-cut illumination only. Fluorescent paints (which emit under UV) and
metallic/pearlescent paints (angle-dependent) cannot be represented by two-constant K-M and are
out of scope.
